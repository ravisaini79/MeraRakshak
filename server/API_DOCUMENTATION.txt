======================================================
         MERARAKSHAK API DOCUMENTATION
======================================================
Base URL: https://merarakshak.onrender.com (or http://localhost:3000)

Note: Most APIs require an Authorization header.
Header: "Authorization: Bearer <your_token>"
Global Note: Almost all API success responses are wrapped in a standard format containing "status": "success", a "message", and the data inside a "response" object (unless otherwise noted).

------------------------------------------------------
1. REGISTER USER & DEVICE
------------------------------------------------------
Endpoint: POST /api/auth/register
Auth Required: No
Content-Type: application/json

Request Body:
{
  "fullName": "John Doe",
  "email": "john@example.com",
  "mobile": "1234567890",
  "password": "password123",
  "address": "123 Main St",
  "imeiNo": "IMEI-123456",
  "deviceModel": "Samsung Galaxy S23",
  "deviceName": "John's Primary Phone"
}

Expected Response:
{
  "status": "success",
  "message": "Request successful",
  "response": {
    "userId": "64b1f...",
    "deviceId": "64b1f...",
    "fullName": "John Doe",
    "email": "john@example.com",
    "mobile": "1234567890",
    "role": "user",
    "token": "eyJhbGciOiJIUzI1NiIs..."
  }
}

6. ADD INTRUDER SELFIE (SECURITY EVENT)
------------------------------------------------------
Endpoint: POST /api/security-events
Auth Required: Yes
Content-Type: multipart/form-data

Form-Data Fields:
- selfieImg (File)
- dateTime (Text): "2026-05-01T15:30:00Z"
- location (Text): "New York, USA"
- tryType (Text): "wrong"
- imeiNo (Text): "IMEI-123456"
- deviceModel (Text): "Samsung Galaxy S23"

Expected Response (Custom Format):
{
  "status": 1,
  "message": "Security event and selfie has been recorded successfully",
  "event": {
    "userId": "64b1f...",
    "deviceId": "64b1f...",
    "image": "https://res.cloudinary.com/yourcloud/image/upload/v123456/tracker_evidence/xyz.jpg",
    "location": "New York, USA",
    "tryType": "wrong",
    "dateTime": "2026-05-01T15:30:00.000Z",
    "_id": "65b5g..."
  }
}

8. GET DEVICE HISTORY / SYNCED DATA
------------------------------------------------------
Auth Required: Yes

- Get Contacts: GET /api/contacts?deviceId=<optional_id>
- Get Call Logs: GET /api/call-logs?deviceId=<optional_id>
- Get Location: GET /api/location?deviceId=<optional_id>
- Get Selfies: GET /api/security-events?deviceId=<optional_id>

Note: If deviceId is omitted, it will automatically return data for the device that made the request.

Expected Response:
{
  "status": "success",
  "message": "Request successful",
  "response": [
    // Array of objects (contacts, call logs, locations, or selfies)
  ]
}
